# Profil de démonstration

L’infographie de Camille est conservée en réserve. Elle n’est pas affichée dans le bloc d’analyse de profil, restauré à sa version précédente à la demande de Ludovic.

Camille Moreau est un personnage fictif. Son post illustre une méthode d’organisation : choisir trois priorités, réserver un créneau pour chacune, reporter le reste.

`camille-infographie.html` est généré avec `modules.infographic_templates.build_html` du dépôt Replikr : modèle `checklist`, style `pastel`, polices Inter, couleur lavande, photo et signature de Camille. Aucun appel à un modèle d’IA. Le WebP associé est l’export complet à 1080 × 1350, qualité 96, sans recadrage du contenu.

Le script de reproduction est `work/build-camille-infographic.py` dans le workspace parent. « … voir plus » est un repère visuel de cet aperçu animé, non un contrôle interactif.
